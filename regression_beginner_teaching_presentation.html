What Regression Tries To Do

Regression studies how an outcome varies with one or more predictors.

  • Outcome: what we want to explain or predict.
  • Predictor: information used to explain or predict the outcome.
  • Noise: variation the model does not explain.
Explain simplyA regression line summarizes a pattern. It does not claim every point is on the line.

Variables, Parameters, Estimators, Estimates

TermBeginner meaningExample
VariableA measured quantity that can change.House size, price, age.
ParameterAn unknown fixed feature of the population model.The true slope in the population.
EstimatorA rule that uses data to estimate a parameter.Least-squares slope formula.
EstimateThe number produced in this sample.Slope = 245 dollars per square foot.
Common mistakeStudents often call the software output "the truth." It is an estimate from one sample, not the population parameter itself.

Essential Algebra for Regression

Distributive law

a(b + c) = ab + ac

Used when expanding fitted values and residuals.

Solving for a variable

y = a + bx
x = (y - a) / b

Used to interpret fitted equations.

PracticeIf price = 50 + 2*size, what size gives price 110? Answer: (110 - 50)/2 = 30.

Summation Notation

Summation notation is just repeated addition written compactly.

sum from i=1 to n of x_i = x_1 + x_2 + ... + x_n
sum_i (a + b x_i) = n*a + b*sum_i x_i
Teaching moveReplace symbols with four boxes. Then return to the formula after the picture is clear.

Functions and Transformations

Function

A rule that maps input to output: y = f(x).

Log

Turns multiplication into addition. Useful for growth rates and skewed positive outcomes.

Exponential

Always positive. Important in logistic and count models.

log(a*b) = log(a) + log(b)
log(a^c) = c*log(a)
Further studyReview functions and transformations before logistic regression; a beginner-friendly path starts with Khan Academy statistics topics.

Derivatives and Optimization

A derivative measures local rate of change. Optimization uses derivatives to find a minimum or maximum.

  • First derivative: slope.
  • Second derivative: curvature.
  • Regression often minimizes a loss function.
If f(x) = x^2, then f'(x) = 2x
Explain simplyRegression fitting is choosing parameter values that make prediction errors small.

Probability Foundations

Expected value

The long-run average of a random variable.

E[X] = sum of x * P(X=x)

Variance

How spread out values are around the expectation.

Var(X) = E[(X - E[X])^2]

The central regression object

E[Y | X = x]

This means the average outcome among cases represented by predictor value x.

Sample, Population, Signal, Noise

  • Population: the larger process or group we care about.
  • Sample: the observed data we actually have.
  • Signal: systematic pattern.
  • Noise: variation not explained by the model.
Key pointStatistical uncertainty comes from the fact that a sample is only one possible draw from a larger process.

Linear Algebra Without Fear

Linear algebra lets us express many regression equations at once.

Vector

An ordered list of numbers.

y = [y1, y2, y3]

Matrix

A rectangular table of numbers.

X = rows of observations, columns of predictors

Dot product

A weighted sum.

a dot b = sum_i a_i b_i
Matrix dimensions: (n x k)(k x p) = (n x p)

Python Foundations for Regression

  • Write functions that return values, not just print.
  • Validate dimensions and empty inputs.
  • Use tests with known answers.
  • Separate data preparation, model fitting, and reporting.
def mean(values):
    values = [float(v) for v in values]
    if not values:
        raise ValueError("mean requires at least one value")
    return sum(values) / len(values)
Classroom pointRegression software can hide calculations. Pure Python forces students to understand what every number means.

Numerical Error and Stability

Floating point reality

Computers approximate most real numbers. Mathematically equal expressions may differ slightly in code.

Stable algorithms

Some formulas are correct on paper but fragile on a finite-precision computer.

def is_close(a, b, rel_tol=1e-9, abs_tol=1e-12):
    return abs(a - b) <= max(
        abs_tol,
        rel_tol * max(abs(a), abs(b))
    )
ImportantNormal equations are mathematically valid, but QR/SVD methods are often more numerically stable for least squares.

Simulation: Theory You Can Test

A simulation creates data from a known process so students can see whether an estimator behaves as expected.

  1. Choose true parameters.
  2. Generate predictors.
  3. Add random noise.
  4. Fit the model.
  5. Repeat many times.

Simple Linear Regression

Simple linear regression uses one predictor to model the conditional mean of an outcome.

y_i = beta_0 + beta_1 x_i + error_i
  • beta_0: intercept.
  • beta_1: slope.
  • error_i: unexplained part.
Further studySciPy linregress calculates a simple least-squares regression and returns slope, intercept, R value, p-value, and standard errors.

Least Squares: Fit by Minimizing Errors

Least squares chooses the line that minimizes the sum of squared residuals.

residual_i = y_i - predicted_y_i
SSR = sum_i residual_i^2
ExplainSquaring makes negative and positive errors both count as bad, and it penalizes large errors more heavily.

Slope and Intercept Formulas

Slope

b1 = sum((x_i - xbar)(y_i - ybar)) / sum((x_i - xbar)^2)

Slope is covariance-like movement divided by predictor variation.

Intercept

b0 = ybar - b1*xbar

The fitted line passes through the point of sample means.

Class exerciseWith points (1,2), (2,4), (3,5), compute the slope and intercept by hand, then verify in Python.

Multiple Linear Regression

Multiple regression uses several predictors at once.

y = beta_0 + beta_1*x1 + beta_2*x2 + ... + beta_k*xk + error

Interpretation

A coefficient is the expected change in outcome for a one-unit increase in that predictor, holding the other included predictors fixed.

Matrix form

y = X beta + error
beta_hat = (X'X)^(-1) X'y
Further studyNumPy least squares solves a @ x = b in the least-squares sense and reports solution, residuals, rank, and singular values.

Projection Geometry

OLS projects the outcome vector onto the column space of the design matrix.

  • Fitted values are the projection.
  • Residuals are the leftover vector.
  • Residuals are orthogonal to the model's column space.
X' residuals = 0

Regression Assumptions

AssumptionWhy students should care
Correct functional formThe model should represent the main pattern reasonably.
No perfect multicollinearityCoefficients must be identifiable.
Zero conditional meanNeeded for unbiased causal-style slope interpretation.
HomoskedasticityNeeded for classical standard error formulas.
NormalityMainly helpful for exact small-sample inference.
Independence or modeled dependenceNeeded because repeated/clustered data can understate uncertainty.
Teaching cautionDo not teach assumptions as a checklist of magic words. Teach what breaks when each one fails.

Inference: Standard Errors and t Tests

Standard error

How much an estimate would vary across repeated samples.

t statistic

t = (estimate - null_value) / standard_error

Measures how many standard errors the estimate is from the null value.

95% confidence interval = estimate +/- critical_value * standard_error
Plain languageA confidence interval is not a guarantee that one student's interval contains the truth. It is a procedure with long-run coverage under assumptions.

Significance Is Not Importance

  • A tiny effect can be statistically significant in a huge sample.
  • A meaningful effect can be non-significant in a small noisy sample.
  • Always report effect size, uncertainty, and practical context.

Prediction vs Mean Response

Confidence interval for mean

Uncertainty about the average outcome at a predictor value.

Narrower because averages are more stable.

Prediction interval

Uncertainty for one new individual's outcome.

Wider because individuals vary around the mean.

Measuring Model Fit

R-squared

Proportion of sample outcome variation explained by the fitted model.

R^2 = 1 - SSE/SST

Error metrics

  • MAE: average absolute error.
  • RMSE: square root of average squared error.
  • Use multiple metrics when possible.
CautionA high R-squared does not prove causality, correctness, or future performance.

Residual Diagnostics

Residual plots help reveal what the model missed.

Further studystatsmodels regression diagnostics gives practical diagnostic examples.

Leverage, Outliers, and Cook's Distance

  • Outlier: unusual outcome value.
  • High leverage: unusual predictor value.
  • Influential point: changes the fitted model noticeably.
  • Cook's distance combines residual size and leverage.

Transformations and Nonlinear Terms

Centering/scaling

Makes coefficients and optimization easier to handle.

Log transform

Useful for positive skewed variables and multiplicative relationships.

Polynomial/splines

Allow curved relationships while regression remains linear in coefficients.

Categorical Variables and Interactions

Categorical variables

Convert groups into indicator columns, often called dummy variables.

group_B = 1 if group is B, else 0

Interactions

Allow one predictor's effect to depend on another predictor.

y = b0 + b1*x + b2*z + b3*(x*z)
Further studypandas.get_dummies documents common categorical encoding used before regression.

Validation and Data Leakage

  • Train set: fit model and choose preprocessing.
  • Validation/cross-validation: compare model choices.
  • Test set: final untouched evaluation.
  • Leakage: information from outside the training data sneaks into training.
Further studyscikit-learn cross-validation guide explains estimator evaluation and cross-validation workflows.

Bias-Variance Trade-off

High bias

Model is too simple. It misses systematic structure.

High variance

Model is too sensitive to the sample. It follows noise.

Regularization: Ridge, Lasso, Elastic Net

Regularization adds a penalty to reduce overfitting and stabilize coefficients.

MethodPenalty ideaEffect
RidgePenalizes squared coefficient sizeShrinks coefficients, usually keeps all predictors.
LassoPenalizes absolute coefficient sizeCan set some coefficients exactly to zero.
Elastic netMixes ridge and lassoUseful with correlated predictors.
loss = fit_error + penalty_strength * coefficient_penalty
Further studyscikit-learn LinearRegression is the baseline API; then compare with Ridge/Lasso classes in the same library.

Logistic Regression

Logistic regression models a probability for a binary outcome.

p = 1 / (1 + exp(-(b0 + b1*x)))
  • Output stays between 0 and 1.
  • Coefficients act on log-odds.
  • Classification needs a threshold.
Further studyscikit-learn LogisticRegression documents the predictive API and penalty options.

Regression and Causal Claims

Regression alone does not prove cause and effect.

  • Prediction: can we forecast Y?
  • Association: how does Y vary with X?
  • Causation: what would happen to Y if X were changed?

Those are different questions.

Causal cautionBad controls and omitted variables can make coefficients misleading.

From-Scratch Python Workflow

Why do it?

  • Understand every number in the output.
  • Learn dimension checks.
  • See where numerical problems occur.
  • Build confidence before using libraries.
def simple_linear_regression(x, y):
    xbar = mean(x)
    ybar = mean(y)
    numerator = sum((xi-xbar)*(yi-ybar)
                    for xi, yi in zip(x, y))
    denominator = sum((xi-xbar)**2 for xi in x)
    slope = numerator / denominator
    intercept = ybar - slope*xbar
    return intercept, slope

End-to-End Regression Checklist

  1. State the question.
  2. Understand how data were generated.
  3. Audit missing values and units.
  4. Explore without overfitting.
  5. Define a simple baseline.
  6. Split data or design validation.
  1. Build preprocessing inside a pipeline.
  2. Fit and diagnose residuals.
  3. Evaluate with more than one metric.
  4. Test sensitivity.
  5. Interpret only within the data range.
  6. Preserve reproducibility.

Common Mistakes and Corrections

MistakeCorrection
Using R-squared as the only measure of qualityAlso examine residuals, validation metrics, and purpose.
Interpreting coefficients causally by defaultSeparate prediction, association, and causal questions.
Preprocessing before train/test splitFit preprocessing on training data only.
Ignoring outliers and leverageInspect influence and report sensitivity.
Trusting software output blindlyCheck assumptions, data, and numerical warnings.

How to Read a Regression Paper

  1. Orientation: what question is asked?
  2. Estimand: what quantity is targeted?
  3. Data generation: how were data collected?
  4. Model and computation: what was fitted?
  1. Diagnostics and robustness: what could fail?
  2. Reproduction: can the result be rebuilt?
  3. Critique and extension: what would improve it?
